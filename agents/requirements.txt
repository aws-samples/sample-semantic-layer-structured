# OpenTelemetry for observability.
#
# ⭐️ aws-opentelemetry-distro is REQUIRED — do not remove it. ⭐️
# The AgentCore runtime env (set by cdk/lib/stacks/backend/agentcore-stack.ts) sets
# OTEL_PYTHON_DISTRO=aws_distro and OTEL_PYTHON_CONFIGURATOR=aws_configurator, and the
# Dockerfiles launch via `opentelemetry-instrument`. Those two entry points are provided
# ONLY by this package. When it is absent, `opentelemetry-instrument` cannot load the
# named distro/configurator, silently leaves the global provider as a no-op
# ProxyTracerProvider (spans get is_recording()==False and trace_id 0x0), and NOTHING
# reaches the `aws/spans` log group — so every AgentCore batch evaluation fails wholesale
# with `evaluatorSummaries: []`. It is also what injects the OTLP endpoint AgentCore
# listens on; there is no OTEL_EXPORTER_OTLP_ENDPOINT in the runtime env to fall back to.
# (Regressed 2026-07-27 in c54186f, which dropped this pin on the incorrect assumption
# that ADOT captured only HTTP/AWS-SDK spans; span telemetry died for ALL agents until
# 2026-08-03. openinference below ENRICHES Strands spans, it does not export them.)
